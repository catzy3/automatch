Не предлагать крупные рефакторы и переписывания без прямого запроса. Пользователь сам говорит что делать следующим.

**Why:** Подтверждено поведением — "нахуй пресеты" (отмена задачи), несколько итераций где пользователь резко сужал скоуп.
**How to apply:** При code review — указывать конкретные проблемы с файлами/строками, не предлагать "было бы хорошо переписать X целиком". Приоритизировать блокеры перед nice-to-have.
